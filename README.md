## 🎮 怎么玩

**装上它，什么都不用做——玩代码，就是玩 DevQuest。**

| 你做了什么 | 你会得到 |
|---|---|
| ✅ 完成一个回合 | +10 XP，连击 +1 |
| 🧰 调用工具 | +1 XP（编辑/命令/SSH 等「锻造师」工具 +2，单回合封顶 +10） |
| 📋 清空待办 | 每个 +15 XP |
| 📝 输出 tokens | 每 10k +1 XP |
| 💥 犯错的回合 | +2 XP（安慰奖） |
| 💪 犯错后爬起来 | 「东山再起」成就 +100 XP |

### 🎓 新手任务链

刚装上时，5 步主线带你熟悉 DevQuest——每完成一步 **+20 XP**，全部完成额外 **+100 XP** 并解锁专属称号**「见习冒险者」**：

```
🚶 完成首个回合   ✏️ 第一次编辑   📋 完成首个待办
⌨️ 运行第一条命令   👀 查看一次进度   →  🏅 见习冒险者
```

面板里实时显示进度（`2/5 步`），做完哪步亮哪步，目标感拉满。

### 🛒 赛季商店

**本赛季赚到的 XP 就是货币**（赛季结束清零重计，天然防通胀）。面板每日任务下方直接购买：

| 商品 | 价格 | 效果 |
|---|---|---|
| 🛡️ 连击保险 | 150 / 400（×3） | 失误回合自动消耗一个，**连击不清零** |
| 🔀 任务重掷 | 120 | 重掷今天的每日任务 |
| 🔥❄️🌿 面板主题 | 300 | 熔火 / 寒霜 / 青翠三款配色 |
| 👑🌟 称号徽章 | 250 | 称号旁展示王冠 / 星芒徽章 |

买了主题和徽章**永久拥有**；保险和重掷是消耗品，需要时随时补充。

### 📅 每日任务

每天 **3 个随机任务**（按日期确定性抽取，同一天所有玩家看到的都一样，21 种任务池）：

- 🗡️ 完成 5 / 15 / 30 个回合
- 🧰 调用 20 / 50 / 100 次工具
- ✏️ 编辑写入 10 / 20 次 · ⌨️ 命令行 10 / 20 次
- 📋 完成 5 / 10 个待办 · 📝 输出 50k / 150k tokens
- 🛰️ 使用 1 次 SSH · 🤝 派出 1 / 2 个子代理
- 💪 失误后重新站起来 · 🌙 凌晨完成 1 个回合 · 🎭 用 8 种不同工具 · 👀 看一眼自己的进度

做完**自动结算 XP**，不用手动领。**天天有目标，天天有奖励。**

3 个任务**全部完成**后，还会解锁当天的 **🎁 每日全清宝箱**——点一下，额外 **+50 XP**（每天一次，第二天重置）：

```
🎁 领取全清宝箱 +50 XP   ← 可点击
🎁 全清宝箱已领取         ← 领完后的状态
```

面板 hero 区下方的金色 **🎁** 按钮，点一下即开，跨天重置——**每天开工先摸一把**。

### 🗓️ 每周挑战

**每周 3 个目标**（按 ISO 周抽取，12 种任务池），进度自动推进、完成自动结算，**3 个全清再领 +100 XP** 周奖励：

- 🗡️ 完成 30 / 60 个回合
- 🧰 调用 200 / 500 次工具 · ✏️ 编辑写入 60 次
- ⌨️ 命令行 80 次 · 📋 完成 30 个待办
- 📝 输出 300k / 800k tokens
- 🤝 派出 5 个子代理 · 🎭 用 15 种不同工具 · 🌙 凌晨完成 5 个回合

```
🗓️ 每周挑战       2026-W33
⬜ 完成 30 个回合    18/30  +120 XP
⬜ 调用 200 次工具  142/200 +150 XP
✅ 输出 300k tokens  312k   +180 XP
🎁 领取全清周奖励 +100 XP    ← 3 个全清后出现
```

**每天干活，周周有目标。**

### 🏅 等级与称号

```
Lv.1-4     学徒
Lv.5-9     工匠
Lv.10-14   锻造师
Lv.15-19   宗师
Lv.20+     传说
```

每 5 级一档称号（面板与工具显示中文称号），每个里程碑都有成就徽章等着你。面板还会显示**本等级已坚持多少天**，升级的瞬间有金色高亮 toast；去商店买一枚 **👑 王冠 / 🌟 星芒徽章**，称号旁边就更闪耀了。

### 🗓️ 赛季

**自动按季度换季**（`2026-S1` = 2026 年 Q1，无需任何配置）：

- 跨季度后的第一次活跃自动开启新赛季
- **赛季 XP / 赛季 tokens 清零重计**，等级与累计 XP 永远保留
- 面板顶部有**赛季冲刺条**：本赛季 tokens 输出 vs 100k 目标进度 + 季度剩余天数倒计时
- 「赛季精英」成就按**本赛季**输出 100k tokens 判定

每个季度都是新的冲刺——**等级是你的历史，赛季是你的本季战绩**。

### 🌍 全局进度

**一个玩家，一份存档**（`~/.dsh/devquest/player.json`）：

- 所有会话、所有项目共享同一份进度——换项目不换号
- 旧版按项目隔离的存档会在升级时**自动合并**进全局档
- 事件水位去重，重启重放不会重复计分

### 🏆 44 枚成就 · 六大门类

**旅程** 初出茅庐 → 百回合大师 → 两百五十回合 → 钢铁意志（连续 25 回合零失误）→ 百折不挠（10 次失败后爬起）

**锻造** 初试锋芒 → 百炼成钢 → 远洋航行（首次 SSH）→ 铸剑大师（500 次编辑）→ 将帅之才（10 个子代理）

**使命** 使命开始 → 使命达人 → 清道夫（单轮待办全清）→ 任务狂人（30 个每日任务）

**时光** 夜猫子 · 早起的鸟儿 · 七日之约 · 月度之约（连续 30 天）· 肝帝（单日 50 回合）

**传奇** 工匠之路 → 锻造宗师 → 宗师之路 → 传说降临（20 级）→ 神话之上（25 级）→ 太阳神（30 级）

> 🥚 还有藏在角落里的隐藏彩蛋，等你亲自发现——解锁前连面板都不会显示。

**成就看得见进度，目标推着你走：**

- 每个可量化的成就都带**进度条**——成就墙格子底部 2px 微进度条，悬浮简介显示 `35/50` 和完整进度
- 成就墙顶部常驻 **「最近的里程碑」** 引导条：永远告诉你「离下一个徽章还差多少」

```
🎯 最近的里程碑 · 五十回合  35/50
▓▓▓▓▓▓▓▓░░░░░░░░░░  70%
```

- 纯条件成就（如「东山再起」「清道夫」）不显示进度，达成即解锁，保持惊喜
- **隐藏彩蛋也有渐进揭示**：进度超过一半时，成就墙里的 🔒 会变成 ❔ 轮廓——你知道它快解锁了，但不知道是什么，悬念拉满

**稀有度：成就也分三六九等** 🎨

44 枚成就按达成难度分级，解锁 toast 与成就墙按稀有度**着色 + 光晕**：

```
普通   常见、上手即有          （初出茅庐 / 首次编辑）
稀有   需一点积累              （五十回合 / 100 次编辑）
史诗   需要坚持                （钢铁意志 / 500 次编辑）
传说   极致成就                （250 回合 / 30 级 / 魔鬼时刻）
```

## ⚙️ 安装

```sh
dsh plugin --profile web add "github:lucky8197/dsh-devquest#main"
```

重启 dsh web → 侧边栏底部出现 ⚔️ → 开始你的冒险。

模型也能查进度、逛商店（连 agent 自己都会好奇）：

```
devquest_status        # 等级 / XP / 连击 / 今日任务
devquest_achievements  # 44 枚成就全清单与解锁状态
devquest_shop          # 赛季商店：查余额/商品，buy=<商品id> 直接购买
devquest_reset         # 重置存档（危险，需 confirm=true）
```
